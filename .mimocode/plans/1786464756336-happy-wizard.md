# Plan: Типизированные статусы TBoxClient

## Проблема
Сейчас `TBoxBridgeService` логирует ошибки (например, `EADDRINUSE` на UDP-порту) только в logcat через `bridgeCallback.onLogMessage()`. Клиенты, подключённые по TCP, получают только UDP-данные — статусы и ошибки до них не доходят.

## Решение
Расширить TCP-протокол байтом-дискриминатором типа фрейма. Добавить типизированные статусы, которые сервис отправляет по тому же TCP-каналу.

### 5. `core/.../tcp/FrameCodec.kt`

Добавить тип фрейма. Новый формат: `[4 байта длина][1 байт тип][payload]`

```kotlin
object FrameCodec {
    const val TYPE_DATA: Byte = 0x01
    const val TYPE_STATUS: Byte = 0x02
    private const val MAX_FRAME_SIZE = 64 * 1024

    // encode: длина включает type byte + payload
    fun encode(payload: ByteArray, type: Byte = TYPE_DATA): ByteArray {
        val totalLength = 1 + payload.size  // type + payload
        require(totalLength <= MAX_FRAME_SIZE)
        return ByteBuffer.allocate(4 + totalLength).apply {
            putInt(totalLength)
            put(type)
            put(payload)
        }.array()
    }

    // decode: извлекает type byte, возвращает Success с data (без type byte) и type
    fun decode(buffer: ByteArray, offset: Int = 0): DecodeResult {
        if (buffer.size - offset < 4) return DecodeResult.Incomplete(4)
        val length = ByteBuffer.wrap(buffer, offset, 4).int
        if (length < 1 || length > MAX_FRAME_SIZE) return DecodeResult.Error("Invalid frame length: $length")
        val totalNeeded = 4 + length
        if (buffer.size - offset < totalNeeded) return DecodeResult.Incomplete(totalNeeded)

        val type = buffer[offset + 4]
        val payloadLength = length - 1
        val payload = ByteArray(payloadLength)
        System.arraycopy(buffer, offset + 5, payload, 0, payloadLength)

        return DecodeResult.Success(payload, totalNeeded, type)
    }

    sealed class DecodeResult {
        data class Success(val data: ByteArray, val consumed: Int, val type: Byte = TYPE_DATA) : DecodeResult()
        data class Incomplete(val neededBytes: Int) : DecodeResult()
        data class Error(val message: String) : DecodeResult()
    }
}
```

**Ключевой момент**: `length` теперь = `1 (type) + payload.size`. При `decode` мы читаем `length` байт после заголовка, первый из них — type, остальные — payload. Это гарантирует, что encode и decode всегда согласованы.

## Сериализация TBoxStatus

Простая бинарная (без зависимостей):

```
TBoxStatus.toByteArray():
  [1 байт: type.ordinal]
  [2 байта: message length (big-endian)]
  [N байт: message UTF-8]
  [2 байта: details length (big-endian, 0 если null)]
  [M байт: details UTF-8]

TBoxStatus.fromByteArray(data):
  читает type ordinal → TBoxStatusType.entries[ordinal]
  читает message
  читает details (если length > 0)
```

Добавить как методы в companion object `TBoxStatus`.
